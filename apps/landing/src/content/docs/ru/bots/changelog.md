API ботов только расширяется: новые маршруты, поля и события добавляются, существующие не меняют смысл. Версию своего сервера смотрите в `GET /api/version` (см. [Версия API](../reference/version)).

## Совместимость

- Новые поля в ответах и событиях появляются без предупреждения — пропускайте незнакомые поля.
- Новые значения перечислений (виды уведомлений, типы событий) тоже — обрабатывайте неизвестное значение как «другое».
- Маршрут, закрытый для ботов, может открыться в новой версии; открытый не закрывается без записи в этом журнале.
- Контракт вебхука доски остаётся версии `1`: поля только добавляются.
