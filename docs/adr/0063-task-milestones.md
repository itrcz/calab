# ADR-0063: Вехи внутри задачи (2026-10-04)

**Статус: принято.** Миграция — следующий свободный номер на момент реализации (сейчас заняты 00063–00065 ветками
2.3.0). Опирается на ADR-0042 (задачи, подзадачи один уровень, таймлайн), ADR-0058 (фичи доски, чек-листы — образец
вложенной сущности задачи), ADR-0059 (права на карточке). Вехи доски (`board_milestones`) не меняются.

## Контекст
Владелец (04.10, скриншоты Linear «Milestones» проекта): «для тасок майлстоуны должна быть возможность задать —
в рамках таски, не в доске». У большой задачи — свои этапы со сроками, ромбы на её полосе таймлайна.

## Решение
1. **Модель**: `task_milestones (id uuidv7, task_id → tasks CASCADE, name 1..60, due_on date NULL, position double,
   completed_at NULL, completed_by NULL, created_by, created_at, updated_at)`, ≤ 20 на задачу. Подзадача может
   ссылаться на веху **своей родительской задачи**: `tasks.task_milestone_id → task_milestones SET NULL`
   (проверка в коде: веха принадлежит `parent_id` подзадачи; при смене родителя ссылка сбрасывается).
2. **Прогресс вехи**: есть привязанные подзадачи → `done / total` (подзадачи в статусах completed/cancelled;
   cancelled в total не входит), веха выполнена, когда все done (`completed_at` ставится/снимается автоматически);
   нет подзадач → `completed_at` переключает человек. Счётчики считает сервер и отдаёт в `TaskMilestone`.
3. **Права** — как поля задачи: менять — тот, кто правит задачу (`canEdit`, включая исполнителя по карточке,
   ADR-0059); видеть — все, кто видит задачу (`TaskBits ≠ 0`). Фича доски: используем существующий переключатель
   `BOARD_FEATURE_MILESTONES` (выключен — секции нет, запрос на создание → `409 FEATURE_DISABLED`).
4. **API/контракт**: `Task.milestones` (только `GET /tasks/{id}`, как чек-листы) + `Task.milestone_progress`
   (`done`, `total` по всем вехам — для карточки); `POST /api/tasks/{id}/milestones {name, due_on?}`,
   `PATCH /api/task-milestones/{id} {name?, due_on?, position?, completed?}`, `DELETE /api/task-milestones/{id}`;
   подзадача — `PATCH /tasks/{id} {task_milestone_id}`. Журнал задачи: `milestones` (before/after) — вебхук доски и
   правила (ADR-0060) видят его как любое изменение. Событие шлюза — существующий `TASK_UPDATE` родителя (вехи — часть
   задачи), без нового номера. Боты — как люди.
5. **Клиент** (по скриншотам владельца): в панели задачи секция «Вехи» (сворачиваемая, ▾) с «+»: строка ввода —
   ромб, «Название вехи», кнопка-календарь (наш `DateMenu`, не системный input) с «Целевая дата», ✕, ✓ (↩ — сохранить,
   Esc — отмена); строка вехи — ромб (заливка = выполнена, красная обводка = просрочена), название, «5 окт», прогресс
   «3/5», меню «⋯» (переименовать, дата, отметить выполненной, удалить), D&D порядок. У подзадачи — поле «Веха»
   (выбор из вех родителя). Таймлайн: ромбы вех на полосе задачи в их датах с подписью под ромбом (как скриншот 5),
   подсказка — название, дата, прогресс. Карточка канбана — чип `◇ 2/4` при наличии вех. i18n 4 языка.
6. Тесты: интеграционные `TestTaskMilestones` (CRUD, лимит, права исполнителя по карточке и без прав, фича выключена,
   привязка подзадачи только к вехе родителя, автоматическое завершение, журнал), vitest (секция, таймлайн-геометрия
   ромбов), QA-скриншоты. Документы: 04, 16, 19 (+.en), 08, 21, TESTING, CHANGELOG.

## Дополнение (04.10): шкала таймлайна «меньше цифр»
Владелец (скриншот Linear): «синяя — текущая, серая — куда навёл курсор; меньше цифр, лаконично и понятно».
- Шкала: подписи чисел только у начала недели (пн), месяц — одной подписью строкой выше у первой недели месяца;
  выходные — подложка без подписей; на «Квартале» — только месяцы.
- «Сегодня» — таблетка акцента «4 ОКТ» на шкале + вертикаль акцента 1 px через сетку (заменяет текущую линию 2 px).
- Наведение — серая таблетка с датой под курсором («25 СЕН») + вертикаль `fg` 25 % 1 px; отдельный листовой
  компонент: позиция в локальном состоянии, `pointermove` → `requestAnimationFrame`, без таймеров и записи в сторы;
  скрывается при уходе курсора; при перетаскивании полосы показывает дату края.
- Задачи вне видимого окна — в строке подпись muted «← янв 2025» / «май 28 – авг 27 →» (стрелка в сторону задачи);
  клик прокручивает шкалу к задаче.
- Название задачи — над полосой (как у Linear), внутри полосы — только при отсутствии места сверху (компактный режим).
- Формат дат — локаль пользователя, короткие месяцы прописными на шкале («СЕН», «ОКТ»).

## Не входит
Вехи у подзадач; зависимости между вехами; график Progress (объём/начато/завершено во времени) — следующий шаг.
