Превышение лимита частоты даёт `429 ERROR_CODE_RATE_LIMITED` с заголовком `Retry-After` (секунды); лимита тарифа — `409` с `reason: "PLAN_LIMIT"` и полями `used` / `limit`. Значения ниже — облака Calab и настроек по умолчанию; на своём сервере оператор может их изменить.

## Частота запросов бота

| Что | Лимит |
|---|---|
| Все запросы бота | 30 в секунду, всплеск 30 (`BOT_RATE_PER_SEC`) |
| Сообщения бота | 20 в минуту по всем комнатам и DM (`BOT_MESSAGES_PER_MIN`) |
| Сообщения в одну комнату | 5 за 5 секунд — общий лимит для всех |
| Новые DM | 10 сразу, 30 в час |
| Сброс пароля ящика | 3 в час на человека, 10 в час на бота |
| Загрузка файлов | 30 сразу, 120 в час |
| Загрузка стикеров | 10 пакетов сразу, 60 в час |
| Приглашения письмом | 20 сразу, 30 в час; один адрес — не чаще раза в сутки |
| Создание и правка встреч | 30 сразу, 120 в час |
| Звуки в звонке | 1 раз в 2 с на бота, 5 за 10 с на комнату |
| Телефонные звонки | 20 в час на пространство |
| `TYPING` в gateway | раз в 3 с на комнату |

## Размеры

| Что | Предел |
|---|---|
| Текст сообщения | 4000 символов |
| Вложений в сообщении | 20 |
| `nonce` | 64 символа |
| История за запрос | `limit` ≤ 100 |
| Команды бота | 100; имя ≤ 32, описание ≤ 256 символов |
| Описание бота | 512 символов; имя — 1–64 |
| Клавиатура под сообщением | 5 рядов × 5 кнопок; `label` ≤ 80 символов, `data` ≤ 512 байт, `allowedUserIds` ≤ 50 |
| Реакции | 3 разных эмодзи одного участника на сообщение |
| Стикер | WebP, стороны ≤ 512, ≤ 512 КБ (статичный) / ≤ 1 МБ (анимированный); до 50 за запрос, до 120 в паке |
| Картинка бейджа | PNG / WebP / JPEG ≤ 128 КБ |
| Чек-листы | 10 на задачу, 100 пунктов в чек-листе |
| Вехи внутри задачи | 20 на задачу |
| Категории досок | 50 на пространство |
| Временные комнаты | 20 на пространство, 5 на создателя |
| Подписка `SUBSCRIBE` | 100 комнат |

## Gateway

| Что | Предел |
|---|---|
| Сокетов на токен бота | 1 |
| Входящий кадр | 64 КиБ |
| Очередь отправки | 256 кадров, переполнение — `4008` |
| `TYPING` / `SUBSCRIBE` / `PRESENCE_UPDATE` | 10 подряд и 2 в секунду, лишние отбрасываются |
| Флуд | больше 50 кадров в секунду устойчиво — `4008` |
| Heartbeat | около 41 с; без heartbeat 2 × интервал + 10 с — `4009` |
| Буфер `RESUME` | около 5 минут или 1000 событий |

## Вебхуки

| Что | Значение |
|---|---|
| Ответ | любой `2xx` за 10 с |
| Повторы | 1 мин, 2, 4 … до 1 часа между попытками |
| Жизнь доставки | сутки |
| Отключение | после суток ошибок подряд |
| Тело вебхука доски | до 256 КБ |
| Проверка вебхука доски (`ping`) | раз в 10 с |

## Тарифы

| Лимит | Free | Team | Business |
|---|---|---|---|
| Участников в пространстве (боты считаются, гости — нет) | 50 | 100 | 500 |
| Ботов | 1 | 5 | 20 |
| Досок | 3 | 30 | 50 |
| Форм на доску | — | 5 | 20 |
| Хранилище файлов | 5 ГиБ | 300 ГиБ | 1 ТиБ |
| Человек в голосовой комнате | 5 | 15 | 50 |
| Стикерпаков / стикеров | 1 / 200 | без лимита | без лимита |
| Чек-листы | — | есть | есть |
| Вебхук доски, телефония | — | — | есть |
| Автоматизации досок | — | есть | есть |

На своём сервере (Enterprise) лимиты задаёт оператор.

## Сроки жизни токенов

| Токен | Срок |
|---|---|
| Токен бота | бессрочно, до перевыпуска или отзыва |
| Токен LiveKit из `POST /api/rooms/{id}/join` | 10 минут; подключиться нужно за 15 с |
| OAuth access-токен | 5 минут |
| OAuth authorization code | 1 минута |
| OAuth refresh-токен | 8 часов, или 30 минут без использования |

Подробно — [Форматы токенов](./tokens) и [OAuth: токены и сроки](../oauth/tokens).
