# ADR-0164: Администраторы пространства загружают файлы сверх лимита пространства — до потолка 4 ГБ (2026-11-07)

Дополняет [ADR-0155](0155-upload-limits-per-workspace.md). Доска CBF-163.

## Контекст
Перенос архивов из Я360 на Диск ботом от имени владельца (`Calab-On-Behalf: owner`): не прошли файлы
больше 50 МБ (до 139 МБ). Лимит файла по ADR-0155 один на пространство (`MAX_FILE_SIZE_MB` или
`workspaces.max_file_mb`), роль загружающего на него не влияет. Отдельно: `413` отдаёт не Calab, а
ingress Nginx прода — тело режется около 50 МБ при положенных по docs/06 4200 МБ.

## Решение
1. **Кто**: администраторы пространства — его владелец и участники со встроенной ролью «Админ»
   (`ADMINISTRATOR` выдаётся только ей). Гость — никогда. Отдельного права роли и второго лимита в
   админке нет (решение лида на CBF-163): администратор и так может всё в пространстве, а потолок
   защищает сервер.
2. **Сколько**: до жёсткого потолка `config.MaxFileSizeCapMB` = 4096 МБ (ADR-0155 §4), выше — 413
   `FILE_TOO_LARGE` с `limit` = потолок, ответ до чтения тела по `Content-Length`. Нового env нет.
   Остальные — по лимиту пространства, 413 `FILE_TOO_LARGE` с его `limit`, как раньше.
3. **Через бота**: права считаются по `Identity.UserID`, то есть по человеку, от имени которого бот
   действует (ADR-0106 «от имени владельца», ADR-0111 «от имени участника»): бот от имени
   администратора — потолок, от имени участника — лимит пространства. Сам бот (без заголовка) —
   участник со своими ролями, лимит пространства.
4. **Где** (`files.maxFileFor`): все загрузки в пространство через `files.UploadWith` — Диск, вложения
   чата пространства, вложения задач/комментариев досок, вики — и копия файла в Диск (`CopyInto`). Не
   меняется: DM и заметки (env, non-goal), формы досок (свой `max_file_mb` ≤ 100 МБ, загрузчика нет),
   аватары, стикеры, звуки, редактор документов (`OFFICE_MAX_SIZE_MB`). Возобновляемой/частичной
   загрузки и presigned S3 в Calab нет — один потоковый `POST`.
5. **Остальное без изменений**: частота загрузок (burst / в час), квоты пространства и сервера.
   Потолок «загружено, но не прикреплено» следует лимиту загружающего (`2 × лимит + 2 МиБ`),
   срок чтения запроса — тоже (≈ 2,3 ч на 4 ГиБ).
6. **Клиент**: собственной проверки размера до загрузки у клиента нет; строка ошибки называет
   `ApiError.limit` из ответа, то есть лимит именно этого человека.

## Последствия
- Прокси перед API размер по роли не различает: пропускает тело до потолка, режет API. Конфигурация
  ingress прода живёт вне репозитория — требуемые аннотации в docs/06 и строкой в docs/12.
- Администратор может занять квоту пространства крупными файлами быстрее — это его пространство;
  сервер защищён серверной квотой и потолком файла.
