# ADR-0093: Иконка статуса доски и пикер цвета (2026-10-13)

**Статус: принято.** Дополняет [ADR-0042](0042-boards.md) §2 (статусы: тип и цвет). Выходит в 3.3.0.

## Контекст
Владелец, 13.10: «в настройках, когда выбираем цвет лейбла или статуса, пикер кривой, наезжает друг на друга, сложно выбрать цвет. Иконок статусов добавить побольше: есть полузаполненный — сделать четверть и три четверти, плюс ещё какие-нибудь, типа „согласуют“, для разнообразия». Сейчас иконка статуса жёстко следует типу (`BoardStatusType`: backlog — пунктирный круг, unstarted — пустой, started — половина, completed — галочка, cancelled — крест); пикер цвета — самодельный абсолютный поповер внутри строки списка, который перекрывается соседними строками.

## Решение
1. **Протокол.** `BoardStatus.icon` (string, токен; пусто = иконка по типу, как сейчас) и `icon` в запросах создания/изменения статуса (`optional string`, `""` — сбросить к типу). Сервер проверяет токен по списку (422 иначе); столбец `board_statuses.icon text NOT NULL DEFAULT ''`.
2. **Набор токенов** (одна общая таблица в `packages/protocol` — `STATUS_ICONS`, и в Go `boards.StatusIcons`; тест на совпадение):
   `dashed` · `circle` · `quarter` · `half` · `three-quarters` · `check` · `x` — семейство «прогресс» (круги-пироги, те же, что по типам);
   `eye` (ревью) · `shield-check` (согласовано) · `hourglass` (ждём) · `pause` · `flag` · `star` · `bolt` · `rocket` · `bug` · `inbox` · `archive` · `lock` — разнообразие.
   Рисуются одним компонентом `StatusIcon { icon, type, color }`: пироги — свой SVG (дуга по доле), остальное — lucide 14 px в цвете статуса. Пустой `icon` → токен по типу (`backlog→dashed`, `unstarted→circle`, `started→half`, `completed→check`, `cancelled→x`).
3. **Настройки доски → Статусы.** В строке статуса кнопка иконки открывает поповер-сетку токенов (6 в ряд, 32 px, подпись по hover/`aria-label`, выбранная с кольцом); тип статуса по-прежнему отдельный селект (он определяет семантику — завершён/отменён/в работе — для фильтров и правил), иконка — только вид.
4. **Пикер цвета** (статусы, лейблы, вехи — всё, что использует `ColorDot`): общий `components/ColorPicker.tsx` на Radix `Popover` через портал (`mat-popover`), сетка `PALETTE` 6 × n, свотчи 28 px с зазором 8, выбранный — кольцо, `aria-label` с названием цвета, стрелки/Enter/Esc; на телефоне — карточка по центру (общий рантайм меню/поповеров). Ничего не перекрывается соседними строками, поповер не обрезается прокруткой карточки.

## Последствия
- Протокол: новое поле — обратно совместимо (старый клиент показывает иконку по типу); Opus + второе ревью. Миграция `00086_status_icon.sql`.
- Экспорт/вебхуки статусов отдают `icon` как есть.
- Иконки видны везде, где `StatusIcon`: канбан, список, панель задачи, карточки в чате, «Мои задачи», таймлайн, история (ADR-0091).
