# ADR-0075: macOS — нативная vibrancy окна под тайтлбаром, рейлом и колонкой (2026-10-07)

Исключение из запрета стекла (docs/08 «Материалы», docs/09 #65, решение владельца 28.09).

## Контекст
С 28.09 все материалы сплошные: ни `backdrop-filter`, ни `vibrancy` окна. Замер (docs/14 «Без стекла») показал, что дорого стоило размытие **CSS** под поповером над видео (≈ 5,5 п. п. GPU-процесса, пересчёт на каждый кадр); от снятия `vibrancy` окна разницы в пределах шума не видно — смешивание с рабочим столом делает WindowServer, а не наш композитор. Владелец, 07.10: разрешает **нативное** (не HTML) размытие на macOS, чтобы окно выглядело как родное приложение macOS.

## Решение
- **Только macOS, только нативно.** Main: `vibrancy: 'sidebar'`, `visualEffectState: 'followWindow'` (неактивное окно гаснет само, как у системных приложений), фон окна прозрачный `#00000000`, `transparent: false`. `backdrop-filter` и `--blur-*` по-прежнему запрещены везде.
- **Просвечивает только слой окна**: тайтлбар и рейл разделов (`mat-rail`) и колонка комнат/DM (`mat-sidebar-window`). Контент (лента, композер, заголовок комнаты, островок, поповеры, листы, колонка участников) — сплошной, как был. Корневой класс `vibrancy` ставит листовой `WindowVibrancy` только в десктопной оболочке; вход, онбординг, телефонная раскладка — сплошное тело.
- **Тон сохраняется**: поверх материала — полупрозрачный оттенок (`--vibrancy-rail`, `--vibrancy-sidebar`), порядок «рейл темнее колонки» и текст ≥ 4,5:1 в обеих темах. Внешний вид материала следует `nativeTheme.themeSource` (тема приложения).
- **Откат к сплошному** — одно правило `vibrancyWanted` (`shared/windowMaterial.ts`) для main и renderer: не macOS; выключен «Настройки → Основное → Прозрачность окна» (`AppSettings.windowTranslucency`, по умолчанию вкл.); системное «Уменьшить прозрачность» (`nativeTheme.prefersReducedTransparency` / `prefers-reduced-transparency`); «Слабый компьютер» (`data-low-end`; когда режим появится, он же выключает `windowTranslucency`, чтобы main снял effect view); визуальные тесты.
- Windows/Linux/веб не меняются.

## Последствия
- Градиент `island-fade` под нижним островком на прозрачной колонке выключен: строки уходят под островок, как в нативных сайдбарах.
- Кольца бейджей (`var(--color-rail)`) остаются сплошными — на просвечивающем рейле чуть темнее фона.
- Энергобюджет (docs/14): нужен замер `energy-bench --with WindowServer` с vibrancy и без на реальном Mac (сценарии C/E); если WindowServer растёт заметно — по умолчанию выключить.
