# ADR-0165: Диск — публичная ссылка на папку (2026-11-09)

**Статус: принято.** Меняет [ADR-0094](0094-disk.md) §3 («только для файлов в v1, папки — отложено»),
опирается на [ADR-0161](0161-disk-manage-level.md) («Управление») и
[ADR-0143](0143-office-editing-onlyoffice.md) (просмотрщик документов). Задача CBF-166.

## Контекст
Публичная ссылка была только у файла. Отдать подрядчику или клиенту папку с материалами целиком
приходилось по одному файлу. Нужна ссылка на папку: без входа, только чтение, с навигацией вниз,
просмотром в браузере и скачиванием — и без единой дыры в «Только выбранные».

## Решение
1. **Та же модель и те же маршруты.** `disk_links` не меняется (миграции нет): строка ссылки висит на
   элементе любого вида. `POST/DELETE /api/disk/items/{id}/link` для папки — те же права, что для
   файла: владелец элемента, «Управление» на нём (ADR-0161) или `DISK_MANAGE` пространства (вне
   «Только выбранные»); «Правка» — 403. `DISK_MANAGE` видит ссылку в `DiskItem.link` и снимает её.
   Включение и выключение пишутся в историю папки (`link_on` / `link_off`, автор — кто нажал).
   Боты — теми же маршрутами. Код — те же 43 символа.
2. **Что видно по ссылке.** Поддерево папки, вычисляемое на каждый запрос (добавленное позже видно
   сразу, удалённое в корзину исчезает сразу, вынесенное из папки — пропадает). Элемент входит в
   ссылку, только если **каждый** элемент на пути от папки ссылки (не включая её) до него
   включительно: не в корзине; не «Только выбранные» (`restricted`); не имеет переопределения с
   deny `DISK_VIEW` (роли или человеку). Иначе он и всё под ним не перечисляются, а прямой запрос по
   id — 404. Выше папки ссылки — ничего ни по какому id. Сама папка ссылки может быть
   «Только выбранные» — её открыл тот, кто вправе ею распоряжаться (как у файла в ADR-0094 §3).
   Проверка — на сервере: цепочка `DiskItemPath` от элемента вверх до папки ссылки + один запрос
   переопределений (`ListDiskDenyViewItems`); листинг фильтрует страницу тем же правилом.
   Deny `DISK_VIEW` скрываем сознательно строже, чем просили («Только выбранные»): ссылка не должна
   показывать посторонним то, что закрыто даже от части участников.
3. **Папка ссылки в корзине** — ссылка не отвечает (404), пока папку не восстановят: её содержимое
   лежит в корзине вместе с ней. Ссылка на файл в корзине по-прежнему работает (ADR-0094 §3).
4. **Анонимные маршруты** (`noindex`, `no-store`, `no-referrer`, лимиты Redis на IP, как у файла):
   - `GET /api/public/disk/{code}` — `PublicDiskFile`, для папки `kind = FOLDER` и имя;
   - `GET …/items?parent=&cursor=` — `PublicDiskFolder`: путь от папки ссылки, папки, затем файлы по
     имени (тип, размер, дата), страницы по 200; только для ссылки на папку;
   - `GET …/items/{id}/content` (Range, начало файла = скачивание) и `…/items/{id}/thumbnail`;
   - `GET …/archive?parent=` — «Скачать всё»: zip без сжатия (CPU не тратится на уже сжатые медиа),
     потоком; потолки 2 ГБ суммарно и 5000 элементов поддерева (413 до начала потока), свой лимит
     IP (3 сразу, затем 1 в 5 минут); засчитывается одним скачиванием. `?check=1` — только «влезет
     ли» (204 / 413) под лимитом чтения, без счётчика: страница объясняет отказ, а не скачивает ошибку;
   - `GET …/office?item=&theme=&phone=&lang=` — подписанная конфигурация просмотра документа (ниже).
   Лимиты: чтение 60/мин, байты 30/мин, архив отдельно.
5. **Документы Office** открываются только для чтения в Document Server, как вложение в чате
   (ADR-0143): короткоживущий URL-токен `afile`, привязанный к файлу, ключ просмотра по файлу, без
   сессии и callback, пользователь «Гость» со случайным id. Новой авторизации нет: страница получает
   конфигурацию только для файла, прошедшего проверку п. 2. Выключенный редактор — 404, страница
   показывает карточку «Скачать». `PublicDiskEntry.office` / `PublicDiskFile.office` говорят, что
   файл откроется.
6. **Страница `/d/{code}`** (веб, без входа): ссылка на файл — карточка (превью, размер, «Открыть»,
   «Скачать»); ссылка на папку — заголовок, срок, «Скачать всё», крошки от папки ссылки, строки
   (папки, затем файлы: иконка/миниатюра, имя, размер, дата, «Скачать»), папка открывается на месте
   (`?folder=<id>`, «Назад» браузера работает). Файл — те же просмотрщики, что в приложении
   (CBF-22: картинки, видео, аудио, текст/код/Markdown/CSV, PDF — не на телефоне), документы — п. 5,
   прочее — карточка «Скачать». Caddy отдаёт `/d/*` с `noindex` и `no-store`, как `/w/*`.

Вне объёма: пароль на ссылку, «Без скачивания» — отдельной задачей (**сделано [ADR-0167](0167-disk-link-password-view-only.md)**).

## Последствия
- Ссылка на папку — снимок прав «сейчас»: закрыть подпапку от ссылки можно «Только выбранные»
  или запретом просмотра; выключить ссылку целиком — «Ссылка…».
- Открытая конфигурация документа живёт 12 ч (ADR-0143), URL файла — минуты: после выключения
  ссылки уже открытый документ ещё можно дочитать, новый — нет.
- Просмотр видео/PDF/текста с начала файла засчитывается скачиванием, как у ссылки на файл.
