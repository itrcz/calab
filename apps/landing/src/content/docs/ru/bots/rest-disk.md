> [!NOTE]
> **Скоро.** Сейчас у ботов нет доступа к Диску пространства: все маршруты Диска (`/api/workspaces/{id}/disk/…`, `/api/disk/items/…`) отвечают боту `403 FORBIDDEN`, `reason: "BOT_NOT_ALLOWED"`, а роли не дают боту прав на Диск. API Диска и Вики для ботов запланирован — следите за [журналом изменений](./changelog). Пока файлы для сообщений и задач бот загружает через [Файлы](./rest-files).
